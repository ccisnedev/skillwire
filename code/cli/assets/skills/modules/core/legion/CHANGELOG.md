# Changelog

## 1.0.0 — 2026-08-26

First release under `skillwire_cli`.

Relocated from `inquiry`, where it had been parked because there was nowhere
else to put a skill that belonged to no single project. It is transversal, and
carries no reference to inquiry's cycle, its agents or its paths — which is
what made the move a copy rather than a rewrite.

Its provenance there: commit `3b6b9cc`, "rename skill Invoke-ExpertCouncil to legion". Issues #191.

The frontmatter gained `license` at the top level (R13.7) and the two metadata
keys R13.6 fixes: `version`, and `skillwire-origin` naming the consumer that
transports it.
