# skillwire — the package

The reusable core. Domain model, pure reconciliation, host matrix, visibility
graph, ledger.

Depends on no consumer CLI. `skillwire_cli`, `macss` and `inquiry` all embed it.

Written in prose as *the `skillwire` package*, never as a bare `skillwire` — that
names the executable. See
[`../../docs/adr/0004-writing-the-name.md`](../../docs/adr/0004-writing-the-name.md).
